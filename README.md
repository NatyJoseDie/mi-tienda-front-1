Mi Tienda Front-1
Descripción
Mi Tienda Front-1 es un proyecto de front-end para una tienda en línea. El proyecto está desarrollado con React y utiliza Next.js como framework.

Estructura del Proyecto
El proyecto se divide en las siguientes carpetas:

src: Contiene el código fuente del proyecto.
app: Contiene los componentes y páginas de la aplicación.
admin: Contiene los componentes y páginas de la sección de administración.
catalogo: Contiene los componentes y páginas de la sección de catálogo.
carrito: Contiene los componentes y páginas de la sección de carrito.
login: Contiene los componentes y páginas de la sección de login.
components: Contiene los componentes reutilizables de la aplicación.
context: Contiene los contextos de la aplicación.
types: Contiene los tipos de datos de la aplicación.
public: Contiene los archivos estáticos de la aplicación.
styles: Contiene los estilos de la aplicación.
Páginas
El proyecto tiene las siguientes páginas:

/: Página de inicio.
/admin: Página de administración.
/catalogo: Página de catálogo.
/carrito: Página de carrito.
/login: Página de login.
Componentes
El proyecto tiene los siguientes componentes:

Header: Componente de cabecera.
Footer: Componente de pie de página.
ProductCard: Componente de tarjeta de producto.
ProductForm: Componente de formulario de producto.
Cart: Componente de carrito.
Tecnologías Utilizadas
React
Next.js
TypeScript
CSS
Instalación
Para instalar el proyecto, sigue los siguientes pasos:

Clona el repositorio.
Instala las dependencias con npm install.
Inicia el proyecto con npm run dev.
Uso
Para utilizar el proyecto, sigue los siguientes pasos:

Inicia el proyecto con npm run dev.
Accede a la página de inicio en http://localhost:3000.
