# 🚀 Instrucciones Rápidas - Sistema de Ventas

## ✅ ¡Problema Solucionado!

Tu sistema de ventas ahora funciona en **Modo Demo** mientras no tengas el backend ejecutándose.

## 🎯 Cómo Usar el Sistema Ahora

### 1. Ve a Ventas Minoristas
- Navega a: `http://localhost:3001/admin/ventas-minoristas`
- Verás un indicador: **🔧 Modo Demo (Sin Backend)**

### 2. Registrar una Venta
1. **Selecciona un producto** del dropdown (ahora hay 3 productos demo)
2. **Ajusta la cantidad** y **precio de venta**
3. **Haz clic en "Agregar al Carrito"** 🛒
4. **Completa los datos del comprador** (nombre obligatorio)
5. **Haz clic en "Registrar Venta"** ✅

### 3. Ver Ventas Registradas
- Haz clic en **"Ver Ventas"**
- Verás todas las ventas que has registrado
- Puedes **exportar a Excel** si necesitas

## 🔄 Cambiar a Backend Real

Cuando tengas el backend funcionando:
1. Haz clic en **"🔄 Reintentar Backend"**
2. El sistema intentará conectarse automáticamente
3. Si se conecta, verás: **🟢 Conectado al Backend**
